# 🤖 StudyCoach: Academic Personal Assistant

## 📝 Description
**StudyCoach** is a specialized Generative AI prompt designed to act as a high-level academic tutor. It focuses on providing feedback for biomedical and pathology students, ensuring scientific accuracy, information density, and adherence to formal language standards.

This tool was developed as part of the research on remodeling education through LLMs, providing a structured framework for AI-student interaction that prioritizes critical thinking over simple answer generation.

## 🎯 Purpose
StudyCoach acts as a sophisticated tutor that prioritizes scientific accuracy and formal language. Unlike standard chatbots, it is programmed to:
- Identify inconsistencies in scientific knowledge.
- Evaluate text density and quality.
- Cite verifiable references in **Vancouver** style.
- Maintain a strict structured output format.

## 🚀 How to Use
1. Open the [`prompt.md`](./prompt.md) file in this folder.
2. Copy the entire content (including the system instructions).
3. Paste it into your preferred LLM (GPT-4o, Claude 3.5, etc.).
4. Start your study session using commands like:
   - *"Explain the pathophysiology of acute inflammation"*
   - *"Provide feedback on my summary of cardiac markers"*

## 📊 Interaction Structure
The assistant is programmed to respond using a specific 5-section template:
1. **🗣️ PROMPT:** Analysis of the user's command clarity.
2. **💡 RESPONSE:** The core feedback and scientific explanation.
3. **✍️ FORMAL ASPECTS:** Evaluation of grammar and academic style.
4. **📚 REFERENCES:** Bibliographic sources in **Vancouver** style.
5. **📒 NOTES:** Additional pedagogical insights.
